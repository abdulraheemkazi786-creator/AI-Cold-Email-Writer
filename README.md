# AI Cold Email Writer

An AI-powered n8n workflow that generates personalized cold emails automatically using lead information and an AI model.

## Features

* Accepts lead or prospect information
* Generates personalized cold email content
* Uses an AI / LLM API for email writing
* Reduces manual email drafting
* Can be connected with forms, CRMs, spreadsheets, or lead databases
* Can be customized for different industries and outreach campaigns

## Tools Used

* n8n
* AI / LLM API
* Webhooks
* HTTP Requests
* REST APIs
* JSON

## How It Works

1. Lead information is received by the workflow.
2. The workflow processes the lead data.
3. Relevant information is sent to the AI model.
4. AI generates a personalized cold email.
5. The generated email can be reviewed, stored, or sent through an email service.

## Setup

1. Import the workflow JSON file into n8n.
2. Configure your own AI API credentials.
3. Connect the required trigger or data source.
4. Add any required email, CRM, or spreadsheet integration.
5. Test the workflow with sample lead information.
6. Activate the workflow when ready.

## Use Cases

* Sales outreach
* Lead generation
* Personalized cold emailing
* Business development
* Freelance client outreach
* Marketing campaigns

## Security

API keys, passwords, tokens, and private credentials are not included in this repository.

Before using the workflow, configure your own credentials securely inside n8n.
